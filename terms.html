เงื่อนไขการใช้งาน

ขอบเขตสำหรับการใช้ UpVdo บนเครื่องส่วนตัวและบัญชีทดสอบที่ได้รับอนุญาต

ฉบับวันที่ 5 พฤศจิกายน 2026 · การทดสอบส่วนตัว ไม่ใช่บริการสาธารณะ

ในหน้านี้ขอบเขตการใช้งานการอนุญาตและสิทธิ์ตรวจเนื้อหาและการเผยแพร่สถานะและข้อจำกัดบริการภายนอกหยุดใช้งานและติดต่อ

1. ขอบเขตการใช้งาน

UpVdo เป็นเครื่องมือส่วนตัวที่ใช้ n8n บนเครื่องของเจ้าของ เพื่อช่วยเตรียมคำอธิบายและแฮชแท็กจากวิดีโอ และดำเนินการกับบัญชีปลายทางที่ได้รับอนุญาต เว็บไซต์นี้เป็นเอกสารอธิบายเครื่องมือ ไม่ใช่จุดรับไฟล์หรือระบบสมัครใช้บริการสาธารณะ

การเชื่อมต่อ TikTok ในขอบเขตนี้ใช้เพื่อทดสอบ Sandbox และการเผยแพร่แบบส่วนตัวตามสิทธิ์ของบัญชีทดสอบ การมีเว็บไซต์เอกสารหรือการเชื่อมบัญชีไม่ได้หมายความว่าแอปผ่านการตรวจสอบหรือได้รับอนุมัติ production จาก TikTok

2. การอนุญาตและสิทธิ์ในข้อมูล

  • ใช้งานเฉพาะเครื่องและบัญชีที่เจ้าของให้สิทธิ์ รวมถึงการให้สิทธิ์ผ่านขั้นตอนการเชื่อมบัญชีของแพลตฟอร์ม
  • เลือกวิดีโอที่ตนมีสิทธิ์ประมวลผล ส่งไปยังบริการ AI และเผยแพร่ โดยคำนึงถึงสิทธิ์ในภาพ เสียง เพลง และข้อมูลของบุคคลที่ปรากฏในวิดีโอ
  • การสั่งประมวลผลวิดีโอรวมถึงการส่งภาพและเสียงให้ Google Gemini ตามที่อธิบายใน นโยบายความเป็นส่วนตัว
  • เก็บข้อมูลเชื่อมต่อไว้ในระบบที่เจ้าของควบคุม ไม่ใส่รหัสผ่าน โทเคน หรือคีย์ API ในวิดีโอ คำบรรยาย เว็บไซต์เอกสาร หรือไฟล์ที่จะแชร์

3. ตรวจเนื้อหาและการตั้งค่าก่อนเผยแพร่

คำอธิบายและแฮชแท็กที่ AI สร้างอาจคลาดเคลื่อน ควรตรวจชื่อบุคคล เหตุการณ์ ข้อกล่าวอ้าง และความเกี่ยวข้องของคำค้นก่อนนำไปใช้ ชื่อวิดีโอ YouTube ในเครื่องมือนี้อ้างอิงจากชื่อไฟล์โดยไม่รวมนามสกุล

ผู้ใช้เลือกปลายทางและการตั้งค่าที่ต้องการ เช่น ส่วนตัว สาธารณะ เวลาเผยแพร่ และเพลย์ลิสต์ สำหรับ TikTok Sandbox ให้ใช้เฉพาะตัวเลือกที่บัญชีและ API อนุญาต เครื่องมือไม่เพิ่มสิทธิ์บัญชีหรือข้ามข้อจำกัดของแพลตฟอร์ม

โหมดตัวอย่างใช้สร้างข้อความโดยไม่สั่งเผยแพร่ แต่ยังส่งวิดีโอไปให้ Gemini วิเคราะห์ การสั่งงานเผยแพร่จะใช้บัญชีและการตั้งค่าที่เลือกไว้

4. สถานะงานและข้อจำกัด

แยกสถานะส่งคำขอ รอประมวลผล ตั้งเวลา และเผยแพร่แล้วออกจากกัน ผู้ใช้ควรตรวจผลในบัญชีปลายทางเมื่อสถานะยังไม่ยืนยันหรือมีข้อผิดพลาด การเชื่อมต่อที่ยังไม่พร้อมอาจหยุดงานก่อนเริ่มประมวลผลหรืออัปโหลด

งาน YouTube อาจอัปโหลดสำเร็จแต่ตั้งเวลาหรือเพิ่มเพลย์ลิสต์ไม่สำเร็จ ในกรณีนี้ให้ใช้ลิงก์และใบรับที่บันทึกไว้เพื่อตรวจและแก้รายการที่ค้าง แทนการอัปโหลดไฟล์เดิมซ้ำโดยไม่ตรวจสอบ

ความสำเร็จและเวลาประมวลผลขึ้นกับการเชื่อมต่อ โควตา สิทธิ์ API และระบบของผู้ให้บริการ ต้นฉบับ ใบรับ และประวัติในเครื่องอยู่ภายใต้การจัดการของเจ้าของเครื่อง

5. เงื่อนไขของบริการภายนอก

การใช้ Google Gemini, YouTube และ TikTok อยู่ภายใต้เงื่อนไข นโยบายเนื้อหา นโยบายความเป็นส่วนตัว และข้อกำหนด API ของแต่ละบริการ ผู้ใช้ต้องตรวจสิทธิ์บัญชี ข้อจำกัด Sandbox และตัวเลือกการเผยแพร่ที่มีอยู่จริงในบัญชีของตน

UpVdo เป็นเครื่องมือส่วนตัวแยกต่างหาก ชื่อบริการที่กล่าวถึงใช้เพื่ออธิบายการเชื่อมต่อ ไม่ได้แสดงความเป็นพันธมิตร การรับรอง หรือการอนุมัติจากผู้ให้บริการเหล่านั้น

6. หยุดใช้งานและติดต่อ

เจ้าของเครื่องสามารถหยุดโปรแกรม หยุดเวิร์กโฟลว์ เพิกถอนสิทธิ์บัญชี และจัดการข้อมูลเชื่อมต่อในเครื่องได้ การหยุดใช้เครื่องมือไม่ได้ลบโพสต์ที่มีอยู่บนแพลตฟอร์มโดยอัตโนมัติ

ผู้ทดสอบติดต่อเจ้าของเครื่องหรือผู้ดูแล n8n ที่ให้สิทธิ์ใช้งานโดยตรง เมื่อมีข้อสงสัยเกี่ยวกับงานหรือข้อมูลในเครื่อง ไม่มีฝ่ายบริการสาธารณะหรือแบบฟอร์มรับข้อมูลส่วนตัวบนเว็บไซต์นี้

ดูรายละเอียดข้อมูลที่ส่งและการลบข้อมูลใน นโยบายความเป็นส่วนตัว หรือกลับไป ข้อมูลเครื่องมือ
