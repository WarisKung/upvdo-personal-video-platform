UpVdo เป็นเครื่องมือส่วนตัวที่ทำงานบนคอมพิวเตอร์ของเจ้าของ เชื่อม n8n ใน Docker กับ Google Gemini เพื่อช่วยเขียนคำอธิบายและแฮชแท็กจากเนื้อหาวิดีโอ แล้วดำเนินการกับบัญชีที่ผู้ใช้อนุญาต

Purpose & scope

เครื่องมือสำหรับการทดสอบส่วนตัว

UpVdo ใช้กับไฟล์ที่เลือกจากเครื่องและบัญชีของผู้ทดสอบที่ได้รับอนุญาต ไม่มีการเปิดรับสมัครเป็นบริการสาธารณะ และหน้าเว็บไซต์นี้มีไว้แสดงข้อมูลเครื่องมือ นโยบายความเป็นส่วนตัว และเงื่อนไขสำหรับการตั้งค่าการเชื่อมต่อ

การทดสอบ TikTok มุ่งใช้สภาพแวดล้อม Sandbox และการเผยแพร่แบบส่วนตัวตามสิทธิ์ที่บัญชีทดสอบได้รับ เอกสารนี้ไม่ได้ยืนยันว่าแอปผ่านการตรวจสอบหรือได้รับอนุมัติให้ใช้งาน TikTok ใน production

ผู้ใช้เป็นผู้เลือกงานที่ต้องการทำ

ผู้ใช้เลือกวิดีโอ บัญชี ปลายทาง และการเผยแพร่ก่อนเริ่มงาน การเชื่อมต่อที่ยังไม่พร้อมจะต้องตั้งค่าให้เรียบร้อย และสถานะการส่งคำขอจะไม่ถูกแสดงว่าเป็นการเผยแพร่สำเร็จโดยไม่มีผลยืนยัน

เว็บไซต์นี้ไม่มีช่องรับวิดีโอ แบบฟอร์มเข้าสู่ระบบ หรือช่องให้กรอกรหัสผ่านและคีย์ API

How data moves

ข้อมูลเดินทางอย่างไร

การประมวลผลเริ่มจากโปรแกรมในเครื่อง เว็บไซต์เอกสารนี้ไม่ได้เป็นตัวกลางรับวิดีโอหรือเก็บข้อมูลบัญชี

  1. เลือกไฟล์ในเครื่อง

    โปรแกรมอ่านชื่อและชนิดไฟล์ คำนวณลายนิ้วมือไฟล์เพื่อช่วยกันอัปโหลดซ้ำ และสร้างสำเนาพักงานใน Docker ของผู้ใช้

  2. ให้ AI วิเคราะห์เนื้อหา

    n8n ส่งวิดีโอ รวมภาพและเสียง ไปยัง Google Gemini เพื่อสร้างคำอธิบาย แฮชแท็ก และคำค้น ผู้ใช้สามารถสร้างตัวอย่างเพื่อตรวจข้อความได้

  3. ดำเนินการกับบัญชีที่อนุญาต

    เมื่อผู้ใช้สั่งและให้สิทธิ์ ข้อมูลที่จำเป็นจึงถูกส่งไปยัง YouTube หรือการเชื่อมต่อ TikTok ที่ตั้งค่าไว้ ภายใต้ขอบเขตและข้อจำกัดของแต่ละแพลตฟอร์ม

  4. เก็บผลการทำงานในเครื่อง

    มีไฟล์สถานะและใบรับ เช่น รหัสวิดีโอ ลิงก์ คำอธิบาย และสถานะงาน เพื่อช่วยตรวจผลและหลีกเลี่ยงการอัปโหลด YouTube ซ้ำ

Documentation

อ่านรายละเอียดก่อนเชื่อมบัญชี

นโยบายความเป็นส่วนตัว ↗ข้อมูลที่ใช้ ปลายทางของข้อมูล การเก็บรักษา และการควบคุมข้อมูลในเครื่อง เงื่อนไขการใช้งาน ↗ขอบเขต Sandbox การอนุญาต การตรวจข้อความ AI และการตรวจสถานะจริง

การติดต่อและควบคุมการใช้งาน

เครื่องมือนี้ไม่มีฝ่ายบริการสาธารณะ ผู้ทดสอบติดต่อเจ้าของเครื่องหรือผู้ดูแล n8n ที่ให้สิทธิ์ใช้งานโดยตรง เพื่อสอบถามการทำงาน หยุดการเชื่อมต่อ หรือจัดการข้อมูลในเครื่อง โดยไม่ส่งรหัสผ่านหรือโทเคนผ่านหน้าเว็บไซต์นี้
